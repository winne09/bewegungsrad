# Bewegungsrad

Glücksrad für Bewegungspausen im Unterricht. Eine Web-App, läuft im Browser auf iPad und Android, auch offline. Kein Konto, keine Datenübertragung, kein Tracking.

## Funktionen
- 24 Übungen + Joker in drei Gruppen: Aktivieren, Koordination, Dehnen & Ruhe (alle neben dem Stuhl machbar)
- Countdown 20/30/45/60 s mit Gong, Signal „Seite wechseln“ zur Halbzeit
- Ohne Wiederholung: gezogene Felder fallen weg
- Eigene Übungen, gespeichert nur auf dem Gerät
- Vollbild, Leertaste/Fernbedienung zum Drehen
